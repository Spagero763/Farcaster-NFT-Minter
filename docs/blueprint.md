# **App Name**: Farcaster NFT Minter

## Core Features:

- Wallet Connection: Connect to wallet using RainbowKit.
- Token URI Input: Input field for tokenURI.
- NFT Minting: Mint NFT with provided tokenURI on Base Sepolia testnet using the contract: 0x410a6454568a89021d737866E01384447466BbFb
- Transaction Status: Display transaction status and link to BaseScan.

## Style Guidelines:

- Primary color: Vivid blue (#4285F4), reminiscent of blockchain technology and trust. This color stands out well on a light background.
- Background color: Light gray (#F5F5F5) for a clean and modern look, providing a subtle backdrop that doesn't distract from the main elements.
- Accent color: A contrasting yellow (#FFC107), analogous to blue, used for interactive elements like buttons and links to draw attention.
- Body and headline font: 'Inter', a grotesque-style sans-serif, known for its clean and readable design, is used to ensure a modern and accessible presentation. 
- Use simple, outline-style icons to represent different actions and statuses within the application.
- The layout should be clean and centered, optimizing for mobile responsiveness with a single-column design on smaller screens and a maximum width on larger screens.
- Use subtle loading animations during the minting process to keep the user informed without being intrusive.
